Node.js + TypeScript MQTT / Aedes RFID Docker SQLite

Projet Transversal Groupe B

Système de gestion de badges RFID — scan, identification et attribution en temps réel.
Communication entre les équipes via broker MQTT embarqué.

01 — Architecture

Vue d'ensemble

Élec (.12)
Lecteur RFID
→
MQTT Topic
rfid/scan
→
Backend (.11)
Broker + API
→
Frontend
Interface

Le backend embarque son propre broker Aedes — aucune installation externe de Mosquitto requise. La carte RFID est scannée côté élec, l'UID est publié sur rfid/scan, et le backend le traite puis répond sur rfid/response.

03 — Installation

Lancer le projet

// Backend

# Cloner le repo et aller dans le dossier server
cd server
npm install
npm run dev

// Frontend

cd client
npm install
npm run dev

// Docker (production)

# Créer un fichier .env à la racine
DOCKERHUB_USERNAME=votre_username

# Builder les images
docker build -t $DOCKERHUB_USERNAME/projet-server:latest ./server
docker build -t $DOCKERHUB_USERNAME/projet-client:latest ./client

# Pusher sur Docker Hub
docker push $DOCKERHUB_USERNAME/projet-server:latest
docker push $DOCKERHUB_USERNAME/projet-client:latest

# Déployer
docker-compose up -d
04 — MQTT

Topics & Messages

📡

rfid/scan

Publié par la machine élec lors d'un scan de badge.

{ "uid": "A1B2C3D4" }
✅

rfid/response

Réponse du backend après vérification en base de données.

{ "status": true }

Les badges inconnus sont stockés temporairement dans inconnueBadge jusqu'à attribution via le frontend.
